# PD Local

PD Local is for Parkinson's patients and caregivers. Always free to use.
Information and guidance is available to all, even when not logged in. Register
with a physical address and be connected to other users in the same general
location.

## Web App

The web app is a desktop app based on
[The Epic Stack](https://www.epicweb.dev/epic-stack) by Kent C. Dodds.

## Mobile App

For users who want better access to schedule, location and chat services when on
the go.

## Guiding Principles

- Accessibility (a11y) in everything we do. Our users are often challenged by
  small motor tasks like operating a keyboard or moving a mouse.
- Privacy
- No ads
- Free to use forever. This means we are supported by donations and grants from
  large funding bodies.
